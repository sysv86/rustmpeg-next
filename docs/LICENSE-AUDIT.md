# License audit — 2026-10-30

Scope: the entire `rustmpeg-next` workspace (source, manifests, lockfile, tests,
fixtures, and dependency graph).

Verdict: **no license violations found**. All dependencies are permissive; no
GPL, LGPL, AGPL, MPL, SSPL, BUSL, or CDLA code is present. The third-party source
is VTM 24.0 (BSD-3-Clause), dav2d conformance data (BSD-2-Clause), the normative
LC3 tables from liblc3 (Apache-2.0), OpenEXR 3.5.2 `OpenEXRCore` algorithms and
tables (BSD-3-Clause), and one OpenAPV APV conformance vector (BSD-3-Clause), all
recorded in `THIRD_PARTY.md`.

This is an engineering audit, not legal advice.

## Method

1. `cargo metadata --format-version 1` for every package and license expression.
2. `scripts/check-licenses.py`: SPDX-expression evaluation against the allowlist,
   plus a hard rejection of copyleft/data-license tokens.
3. `Cargo.lock` inspection for native build tooling (`cc`, `cmake`, `bindgen`,
   `nasm`) and known C/assembly crates (`ring`, `rustls`, `quinn`).
4. Source scan for copied-code markers, GPL/LGPL/AGPL text, and undocumented
   derivation (`ported from`, `adapted from`, `Copyright (c)`).
5. Automated scan of every Rust source file for an approved SPDX header, plus
   review of `THIRD_PARTY.md`, `NOTICE`, and `LICENSE`.

## Results

### Dependencies

- 137 cargo packages after cleanup.
- License expressions are all permissive combinations of Apache-2.0, MIT,
  BSD-2-Clause, BSD-3-Clause, ISC, Zlib, Unlicense, and Unicode-3.0.
- No package offers only GPL/LGPL/AGPL/MPL/CDLA; no such token remains in any
  expression.
- `Cargo.lock` contains no `cc`, `cmake`, `bindgen`, `nasm`, `ring`, `rustls`,
  `quinn`, or `webpki-root-certs`.
- The GPU stack is pure Rust: `wgpu` (safe Vulkan bindings) with `naga` (runtime
  WGSL parsing and validation). Shaders are compiled at runtime, so no shader
  compiler or C/C++ toolchain is required. `ash` and `gpu-allocator` are not direct
  dependencies; `wgpu-hal` pulls them transitively, with no native build step.
- All seven workspace crates declare `publish = false`. Five inherit the workspace
  `Apache-2.0`; `rustmpeg-video` declares
  `Apache-2.0 AND BSD-2-Clause AND BSD-3-Clause` because it contains VTM-derived
  (BSD-3-Clause) and dav2d-derived (BSD-2-Clause) source, and `rustmpeg-image`
  declares `Apache-2.0 AND BSD-3-Clause` because its OpenEXR module contains
  OpenEXRCore-derived material.

### Per-file licensing

- 197 Rust source files have SPDX headers.
- VVC files containing VTM-derived algorithms or tables use
  `Apache-2.0 AND BSD-3-Clause`.
- AV2 files containing dav2d-derived conformance data use
  `Apache-2.0 AND BSD-2-Clause`.
- OpenEXR files containing OpenEXRCore-derived algorithms or tables use
  `Apache-2.0 AND BSD-3-Clause`; `exr/deflate.rs` stays `Apache-2.0`.
- All other Rust files use `Apache-2.0`.
- The BSD-3-Clause (VTM, OpenEXRCore) and BSD-2-Clause (dav2d) notices are
  reproduced in `THIRD_PARTY.md` and referenced from `NOTICE`.

## Fixes applied during the audit

1. **Removed `quinn`.** It was unused and pulled `ring` (C/assembly build),
   `rustls`, and `webpki-root-certs` (CDLA-Permissive-2.0). This removed the only
   native build step and the only non-allowlisted data license.
2. **Added SPDX headers** to every Rust source file, including the correct
   combined expression for VTM-derived VVC files.
3. **Normalized VTM copyright years** to `2010-2020`, matching VTM's `COPYING`.
4. **Added `LICENSING.md`** (single permissive license surface, no CLA, no GPL/LGPL build).
5. **Added `scripts/check-licenses.py`** so the audit is repeatable.
6. **Updated** `AGENTS.md`, `README.md`, `THIRD_PARTY.md`, and `NOTES.md`.
7. **Normalized VVC provenance** to VTM 24.0 as the sole third-party source and
   removed repository-specific attribution from the docs and per-file headers.

## Residual risk

- The VVC module contains VTM-derived code under BSD-3-Clause. This is compatible
  with Apache-2.0 when the notice is retained; it is not a violation. A strictly
  Apache-2.0-only VVC implementation would require an independent rewrite of
  roughly 8.5k lines, which was not attempted because it would risk correctness
  for no licensing benefit.
- The OpenEXR module contains OpenEXRCore-derived code under BSD-3-Clause. This is
  compatible with Apache-2.0 when the notice is retained; it is not a violation.
  The module is explicitly not described as clean-room.
- The LC3 encoder and decoder contain normative tables transcribed from liblc3
  (Apache-2.0), which is compatible with the project license; attribution is
  retained in `THIRD_PARTY.md` and the per-file headers.
- Test fixtures are generated data. They are not derived from the source of the
  tools that produced them and do not inherit those tools' licenses. The single
  exception is the OpenAPV `qp_F.apv` vector, which is third-party BSD-3-Clause
  data and keeps its attribution.
- Opus and FLAC are implemented from the RFCs; no copyleft reference code was
  consulted or copied. Test-only Ogg parsing and the test range encoder are
  original, RFC-based code.
- Vulkan Compute is implemented from the Vulkan specification and WGSL. No Vulkan
  sample code was copied; every shader is compiled at runtime from source in this
  repository.
- No CLA exists. Contributions are accepted under Apache-2.0 (inbound = outbound).

## Reproduce

```bash
python3 scripts/check-licenses.py
cargo tree -i ring        # must report no matching package
grep -n 'name = "cc"\|name = "cmake"\|name = "bindgen"\|name = "nasm"' Cargo.lock
grep -rIl 'SPDX-License-Identifier' --include='*.rs' crates | wc -l
```
